# Felice Simonelli, PhD: site redesign

A one-page redesign of felicesimonelli.it (Bio, Projects, Publications and Contacts merged into one page).
It is published at `/felice-simonelli/` on the GitHub Pages site.

- `index.html`, `style.css`, `app.js`: static, no build step.
- `data.js`: the 44 projects and 26 publications taken from the original site, each tagged with one or more
  themes. Edit it by hand to add work.
- The work index can be filtered by type, theme, year and text. The filters are kept in the URL
  (`?theme=green,digital&year=2019`), so a filtered view can be shared.

Design: cool grey-blue paper, navy ink, and a single marker yellow kept for active selections.
Bricolage Grotesque (condensed) for display and UI, Source Serif 4 for reading text.
In the hero, the four expertise phrases are links that open the work index already filtered.
Content reflects the original site as of 2021.
